# 数据分析基础模块

本模块涵盖数学建模竞赛中数据分析的核心技能：

## 📚 主要内容

### 1. 数据预处理 (01_数据预处理.py)
- 缺失值处理（均值填充、中位数填充、前向填充）
- 异常值检测与处理（IQR方法、Z-score方法）
- 数据类型转换
- 数据清洗与验证

### 2. 探索性数据分析 EDA (02_探索性数据分析EDA.py)
- 基本统计特征分析
- 单变量分析
- 多变量分析
- 相关性分析
- 数据分布特征

### 3. 统计分析方法 (03_统计分析方法.py)
- 假设检验（t检验、卡方检验）
- 方差分析 (ANOVA)
- 相关系数检验
- 回归诊断

### 4. 数据可视化 (04_数据可视化.py)
- matplotlib基础绘图
- seaborn统计可视化
- plotly交互式图表
- 多种图表类型：柱状图、折线图、箱线图、热力图等

## 🎯 学习建议

1. **按顺序学习**：从数据预处理开始，逐步深入
2. **实践为主**：使用真实数据集练习每个技能
3. **融会贯通**：在实际问题中综合应用多个技巧
4. **形成工具库**：积累可复用的代码片段

## 💡 实际应用

在数学建模竞赛中，好的数据分析能够：
- 发现数据中的规律和异常
- 为模型选择提供指导
- 增强论文的说服力
- 帮助团队更快地理解问题
