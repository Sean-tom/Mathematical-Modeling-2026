# 优化算法库

本模块提供数学建模竞赛中常用的优化算法实现：

## 📚 算法清单

### 传统优化算法

#### 1. 线性规划 (01_线性规划.py)
- 单纯形法基础
- 使用PuLP求解
- 灵敏度分析
- 应用案例：资源配置、生产计划

#### 2. 非线性规划 (02_非线性规划.py)
- 无约束优化
- 约束优化（KKT条件）
- 梯度下降法
- 二阶方法
- 使用scipy.optimize求解

#### 3. 整数规划 (03_整数规划.py)
- 分支定界法
- 割平面法
- 整数规划问题建模
- 0-1规划
- 使用PuLP和Pyomo求解

#### 4. 动态规划 (04_动态规划.py)
- 最优子结构
- 备忘录法
- 自底向上求解
- 经典问题：背包问题、最长子序列等

### 启发式算法

#### 5. 遗传算法 (05_遗传算法.py)
- 种群初始化
- 选择、交叉、变异操作
- 自适应参数
- 多目标遗传算法

#### 6. 粒子群优化 PSO (06_粒子群优化PSO.py)
- 粒子速度和位置更新
- 全局最优和局部最优
- 参数设置
- 收敛性分析

#### 7. 模拟退火 (07_模拟退火.py)
- 温度函数设计
- 接受准则
- 冷却策略
- 应用：旅行商问题、调度问题

## 🎯 算法选择指南

| 问题类型 | 推荐算法 | 复杂度 | 收敛速度 |
|---------|--------|-------|----------|
| 线性约束 | 线性规划 | 低 | 快 |
| 光滑目标 | 非线性规划 | 中 | 中等 |
| 离散决策 | 整数规划 | 高 | 慢 |
| 小规模 | 动态规划 | 中 | 快 |
| 大规模全局 | 遗传算法/PSO | 高 | 中等 |
| 非光滑/多峰 | 模拟退火 | 中 | 慢 |

## 💡 实战技巧

1. **问题建模**
   - 明确决策变量
   - 定义目标函数
   - 列出约束条件

2. **算法选择**
   - 评估问题规模
   - 考虑时间限制
   - 组合多种算法

3. **参数调优**
   - 网格搜索
   - 贝叶斯优化
   - 经验法则

4. **结果验证**
   - 灵敏度分析
   - 对比多种方法
   - 结果合理性检查
