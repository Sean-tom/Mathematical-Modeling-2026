# 预测模型集合

本模块提供数学建模竞赛中常用的预测模型实现：

## 📚 模型分类

### 时间序列模型

#### ARIMA (自回归移动平均模型)
- 平稳性检验 (ADF检验)
- 参数识别 (ACF/PACF)
- 模型拟合与预测
- 适用：中期预测、需要历史数据的场景

#### Exponential Smoothing (指数平滑)
- 一次指数平滑 (SES)
- 二次指数平滑 (Holt)
- 三次指数平滑 (Holt-Winters)
- 适用：短期预测、趋势明显的数据

#### Prophet (Facebook时间序列预测)
- 趋势分量
- 季节性分量
- 假期效应
- 适用：包含假期/节假日的商业数据

#### LSTM (长短期记忆网络)
- 深度学习时间序列
- 序列到序列模型
- 注意力机制
- 适用：复杂非线性关系、大数据量

### 回归模型

#### Linear Regression (线性回归)
- 简单线性回归
- 多元线性回归
- 最小二乘法
- 适用：线性关系、快速建模

#### Ridge & Lasso Regression (正则化回归)
- L1正则化 (Lasso)
- L2正则化 (Ridge)
- 弹性网络 (ElasticNet)
- 适用：特征多、多重共线性问题

#### Polynomial Regression (多项式回归)
- 特征变换
- 过拟合控制
- 最优次数选择
- 适用：非线性但可变换的关系

#### SVR (支持向量回归)
- 核函数选择
- 参数调优
- 鲁棒性强
- 适用：小样本、非线性回归

### 分类模型

#### Logistic Regression (逻辑回归)
- 二分类
- 多分类
- 概率输出
- 适用：二分类、可解释性要求高

#### Decision Tree (决策树)
- 信息增益
- 剪枝策略
- 可视化
- 适用：混合特征、非线性、易解释

#### Random Forest (随机森林)
- 集成学习
- 特征重要性
- 并行计算
- 适用：大数据、高维数据、鲁棒性

#### SVM (支持向量机)
- 线性和非线性核
- 参数C、gamma调优
- 适用：小样本、高维、二分类

#### XGBoost
- 梯度提升
- 正则化
- 缺失值处理
- 适用：竞赛常用、性能优异

#### Neural Network (神经网络)
- 多层感知机
- 激活函数
- 反向传播
- 适用：复杂模式、大数据量

### 聚类模型

#### K-Means
- 中心初始化
- 收敛性
- 最优K选择 (肘部法则)
- 适用：无标签分组、快速聚类

#### Hierarchical Clustering (层次聚类)
- 聚合聚类
- 树状图解释
- 距离度量选择
- 适用：聚类树结构、小样本

#### DBSCAN
- 密度聚类
- 任意形状
- 噪点检测
- 适用：非球形簇、异常检测

## 🎯 模型选择指南

### 根据数据特征选择

| 数据特征 | 推荐模型 | 原因 |
|---------|--------|------|
| 时间依赖 | ARIMA/LSTM | 利用历史信息 |
| 线性关系 | Linear/Ridge | 简单快速 |
| 非线性 | Polynomial/SVM | 能捕捉曲线 |
| 高维稀疏 | Lasso | 自动特征选择 |
| 混合特征 | Random Forest/XGBoost | 处理多类型 |
| 无标签 | K-Means/DBSCAN | 无监督学习 |

### 根据问题类型选择

- **连续预测**：回归模型 (ARIMA/SVR/LSTM)
- **类别预测**：分类模型 (LR/RF/XGBoost)
- **聚类分组**：聚类模型 (K-Means/DBSCAN)
- **异常检测**：孤立森林/DBSCAN
- **多步预测**：LSTM/Prophet

## 💡 实战工作流

1. **数据探索** → EDA分析数据特征
2. **特征工程** → 创建有意义特征
3. **模型选择** → 根据特征选初始模型
4. **模型训练** → 划分训练/验证/测试集
5. **超参调优** → 网格搜索/贝叶斯优化
6. **模型评估** → 使用多个指标评估
7. **集成融合** → 多模型加权组合
8. **结果验证** → 反复检查、敏感性分析
