# 环境配置指南

## 📋 系统要求

- **操作系统**：Windows / macOS / Linux
- **Python版本**：3.8 或更高
- **内存**：最少4GB（推荐8GB以上）
- **硬盘**：至少2GB可用空间

---

## 🚀 快速配置（推荐）

### 第一步：克隆仓库

```bash
git clone https://github.com/Sean-tom/Mathematical-Modeling-2026.git
cd Mathematical-Modeling-2026
```

### 第二步：创建虚拟环境

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 第三步：安装依赖

```bash
pip install --upgrade pip
pip install -r 05_工具与框架/requirements.txt
```

### 第四步：验证环境

```bash
python -c "import pandas as pd; import numpy as np; print('✓ 环境配置成功')"
```

## 📝 常见问题解决

### 问题1：pip安装过慢

**解决方案**：使用国内镜像源

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pandas
```

或修改 `~/.pip/pip.conf` (Unix) 或 `%APPDATA%\pip\pip.ini` (Windows)：

```ini
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题2：scipy/numpy编译失败

**解决方案**：使用预编译轮文件

```bash
pip install --only-binary :all: numpy scipy
```

### 问题3：TensorFlow/PyTorch安装失败

**解决方案**：参考官方文档
- TensorFlow：https://www.tensorflow.org/install
- PyTorch：https://pytorch.org/get-started/locally/

### 问题4：导入模块时提示找不到模块

**解决方案**：确保虚拟环境已激活

```bash
# 检查Python路径
python -c "import sys; print(sys.executable)"
# 应该显示虚拟环境中的Python路径
```

## 🛠️ IDE配置

### VS Code

1. 安装Python扩展
2. 在 `.vscode/settings.json` 中配置：

```json
{
    "python.defaultInterpreterPath": "./venv/bin/python",
    "python.linting.enabled": true,
    "python.linting.pylintEnabled": true
}
```

### PyCharm

1. File → Settings → Project → Python Interpreter
2. 点击齿轮图标 → Add
3. 选择 "Existing Environment"
4. 浏览到 `venv/bin/python` (Unix) 或 `venv\Scripts\python.exe` (Windows)

### Jupyter Notebook

```bash
pip install jupyter notebook
jupyter notebook
```
